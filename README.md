# Piki Food

Piki Food is a food delivery platform that connects customers with restaurants and delivery partners. Users can discover restaurants, order food, make payments, and track deliveries in real time.

## Core Features

### Customer App
- User authentication with OTP
- Browse nearby restaurants
- View restaurant menus
- Search and filter food items
- Add items to cart
- Place food orders
- Manage delivery addresses
- Track order status
- Order history
- Rate restaurants and food
- Receive order notifications

### Restaurant Management
- Restaurant registration
- Manage restaurant profile
- Create and update menu items
- Manage food categories
- Update food availability
- Accept and manage orders
- View sales and order history

### Driver App
- Driver authentication
- View available deliveries
- Accept delivery requests
- Update delivery status
- Navigate to pickup and delivery locations
- Track earnings

### Payment System
- Mobile money payments
- Cash on delivery
- Payment status tracking
- Order payment verification

### Admin Dashboard
- Manage users
- Manage restaurants
- Manage drivers
- Monitor orders
- Manage platform operations

### Real-Time Features
- Live order updates
- Driver location tracking
- Push notifications
- Real-time order status changes

## Technology Highlights
- Modern mobile-first architecture
- Scalable backend API
- Secure authentication
- Real-time communication
- Cloud-based storage
